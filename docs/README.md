# Documentation

This directory contains project-wide documentation that applies across robot models.

- `environment.md`: pinned environment and reproduction details.
- `learning-roadmap.md`: frameworks, algorithms, and recommended study order.
- `data-governance.md`: data, privacy, and large-file rules.
- `adding-a-robot.md`: required process and layout for a new robot model.

Robot-specific usage belongs in `robots/<robot_id>/README.md`, not here. Every new document should be added to this index.
